# 🏋️ AI Fitness Trainer

### Your Personalized AI-Powered Fitness Coach

An AI-powered fitness training platform that generates personalized workout plans, tracks fitness progress, and provides intelligent guidance to help users achieve their health and fitness goals.

---

## 🚀 Overview

AI Fitness Trainer is a modern web application built with Next.js that leverages artificial intelligence to create customized fitness experiences. Users can receive personalized workout recommendations, monitor their progress, and stay consistent with their fitness journey through an intuitive and responsive interface.

The application combines modern web technologies with AI-driven insights to deliver a smart fitness coaching experience.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/vermahoney/ai-fitness-trainer.git

cd ai-fitness-trainer
```

### Install Dependencies

```bash
npm install
```

### Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=

CLERK_SECRET_KEY=

DATABASE_URL=

OPENAI_API_KEY=

VAPI_API_KEY=
```

### Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
